# ClipperTeenager MVP
Platforma wideo na żywo i AR, podobna do TikToka dla nastolatków.

## Instalacja Backend
cd backend
npm install
npm start

## Instalacja Frontend
cd frontend
npm install
expo start

## Zmienne środowiskowe
Skopiuj env.example do .env i uzupełnij MONGO_URI i STRIPE_SECRET_KEY

## Deploy na Render
Użyj render.yaml do automatycznego deployu backend i frontend.
